# 價值投資智慧選股系統（Midterm Project）

以巴菲特式價值投資邏輯為核心，從台灣證交所「公開資訊觀測站（MOPS）」爬取全上市公司（sii）民國 110～114 年的財務報表，計算多項財務指標並依五大條件自動篩選出體質優良的公司，最後以 Streamlit 互動式儀表板呈現分析結果。

> 作者：曹品誠（AIPE03_01）｜簡報：`AIPE03_01_曹品誠_價值投資智慧選股系統.pptx`

## 專題動機

- 想成為股市的受益者，並以巴菲特的**價值投資**為方法論。
- 「聽股票專家千話，不如自己親眼所見一行數據」——與其聽二手解讀，不如自己動手抓原始財報驗證，核心指標即 **ROE（股東權益報酬率）**。

## 為何選 MOPS 作為資料來源

1. **法律效力**：依金管會證券法規，向 MOPS 申報即視同正式公告；虛偽不實者董事長與高階主管須負《證券交易法》刑事責任。
2. **第一手即時性**：重大訊息須於指定時限（通常次一營業日開盤前）刊登，散戶與外資、投信同一時間點看到資訊。
3. **原始數字**：提供會計師簽證的原始財報，避免看盤軟體、財經網站二次加工可能引入的邏輯錯誤。
4. **官方澄清專區**：市場謠言不作數，一切以 MOPS 官方重大訊息為準。

> ⚠ 資料來源聲明：本專題所用財務數據均公開引述自臺灣證券交易所「公開資訊觀測站」，僅供學術研究與教學演示使用（Non-commercial Educational Use Only），不涉及任何商業販售或營利行為。

## 系統流程

1. **建立 Session（Cell 3）**：以 Selenium（含防偵測設定）開啟舊版 MOPS（`mopsov.twse.com.tw`）取得 `jcsession` cookie，複製到 `requests.Session` 後即可高速抓取。
2. **爬取四大報表（Cell 4～6）**：
   - 綜合損益表彙總表（`ajax_t163sb04`）
   - 資產負債表彙總表（`ajax_t163sb05`）
   - 現金流量表彙總表（`ajax_t163sb20`）
   - 股利分派情形（`t05st09_new`，Selenium 操作彈出視窗抓取）
   - 每次請求間隨機延遲，避免被伺服器封鎖。
3. **指標計算（Cell 8）**：自動對應中文欄位名稱，計算 EPS、毛利率、營業利益率、負債比率、ROE、營業現金流（OCF）、自由現金流（FCF）、歷年配息紀錄。
4. **五大篩選條件（Cell 9）**：
   | 條件 | 門檻 |
   |---|---|
   | EPS 為正 | 連續 ≥ 5 年 |
   | 毛利率與營業利益率趨勢 | 持平或走高（與年度相關係數 ≥ -0.1） |
   | 負債比率 | 每年 < 50% |
   | ROE | 每年 > 10% |
   | 現金股利 | 連續 ≥ 5 年配發 |

   五項條件取交集，1,041 家上市公司中共 **46 家**通過篩選。
5. **報表輸出（Cell 10～11）**：輸出 `stock_screening_result.csv`、`mops_master.csv`、`mops_full_data.csv` 與 `mops_data.pkl`，並自動寫出 `stock_app.py`。
6. **啟動儀表板（Cell 12）**：背景啟動 Streamlit 並自動開啟瀏覽器（http://localhost:8501）。

## Streamlit 儀表板功能

- **顯示範圍**四種模式：僅篩選通過 / **AI 供應鏈分類**（晶圓代工、ASIC 與 IP、AI 伺服器、散熱、電源、機殼導軌、高速傳輸、PCB 與 ABF 載板等 8 大族群）/ 全部公司 / 自訂選擇，並可調整年度區間。
- **五個分析頁籤**：
  - 🏆 篩選總覽：指標總表 + ROE vs 負債比、毛利率 vs 營業利益率散點圖（含門檻基準線）
  - 📈 損益趨勢：EPS、毛利率、營業利益率歷年折線圖與分年比較
  - 🏦 資產負債：負債比、ROE 趨勢與「資產 = 負債 + 股東權益」堆疊圖
  - 💰 股利分析：現金股利金額趨勢與配息年份熱力圖
  - 💵 現金流量：營業現金流與自由現金流趨勢及最新年度比較
- 頂部 KPI 卡片即時顯示所選公司的平均 EPS、毛利率、ROE。
- 若 `mops_data.pkl` 不存在，儀表板可退回讀取 `mops_master.csv`，換環境不必重爬。

## 技術重點

- Selenium + requests 混合爬蟲：用瀏覽器取得 session cookie 後改走 AJAX 端點，兼顧成功率與速度。
- 防偵測與節流：隱藏 webdriver 特徵、隨機 User-Agent 等待間隔、封鎖偵測（`SECURITY REASONS`）自動提示。
- 欄位名稱模糊比對（`find_col`）：容忍 MOPS 各年度表格欄名差異，含 MultiIndex 標頭壓平與括號負數解析。
- jupytext 雙格式（`.ipynb` + `.py`）便於版本控管；Notebook 一鍵產生並啟動 Streamlit App。

## 開發過程踩過的坑（與解法）

| 問題 | 解法 |
|---|---|
| 新版 MOPS 網站有 WAF 防火牆會鎖 IP | 改連舊版 `mopsov.twse.com.tw`，先用 Selenium 取得 `jcsession` 再爬取 |
| 表格欄位對不上、資料很髒 | 三步清洗：① 壓平多層標頭（兩層標頭用空格串接）② 關鍵字掃描欄位名 ③ 數字清洗（`"1,234"` → 1234、`(500)` → −500、str → float） |
| 爬取時回傳空列表 | 先直接開網站確認狀況：被鎖 IP → 等待或換 IP；彈窗擋住 → 用 Selenium 模擬點擊取得 HTML 再結構化 |
